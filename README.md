# StageLight Pro — baza wiedzy i test

Responsywna aplikacja edukacyjna dla pracowników oświetlenia scenicznego.

## Zawartość

- 10 modułów wiedzy: BHP, zasilanie, oprawy, fotometria i kolor, DMX/RDM, sieci, konsolety, rigging, workflow oraz diagnostyka,
- wyszukiwarka treści i zapisywany postęp nauki,
- kalkulator ćwiczeniowego obciążenia obwodu jednofazowego,
- test 40 pytań z limitem 50 minut,
- swobodna nawigacja bez wymogu wcześniejszej odpowiedzi,
- automatyczny zapis sesji, wynik i omówienie odpowiedzi,
- responsywny interfejs bez zależności i procesu budowania.

## Uruchomienie

Otwórz `index.html` lub uruchom lokalny serwer:

```bash
python3 -m http.server 8080
```

## Bezpieczeństwo

Materiał ma charakter szkoleniowy. Nie zastępuje dokumentacji producenta, szkolenia stanowiskowego, oceny ryzyka, wymaganych kwalifikacji ani procedur obiektu. Prace elektryczne, riggingowe i na wysokości wykonuj wyłącznie w granicach posiadanych kompetencji.
